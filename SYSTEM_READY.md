## 🎯 Featured Workflows

### Borrowing a Computer + Components
1. Go to **Manage Items** (Admin view)
2. See "MacBook Pro 16" linked to 2 components
3. When borrowed → **all 3 items** auto-selected
4. When returned → **all 3 items** return together

### Complete Approval Workflow
1. User submits request via **New Request**
2. Admin sees it in **Approve Requests**
3. Admin sets return date and approves
4. Item becomes "In-Use" with borrower assigned
5. Operator marks returned via **Hand-Over Tool**
6. Item returns to "Available"

### Excel Export
- Every view has "Export to Excel" button
- Exports all visible data + filtered results
- One-click downloads

### Audit Trail
- **Audit Log** tracks all actions
- Every login, approval, return, status change
- Timestamps, user info, old/new values
- Search and filter by action

## 📞 Need Help?

### Common Issues

**Page not loading?**
- Refresh browser (Cmd+R or Ctrl+R)
- Check console (F12 → Console tab)
- Restart dev server

**Data disappeared?**
- Clear localStorage
- Check browser's storage limits
- Try incognito window

**Styles missing?**
- Clear browser cache
- Restart dev server
- Check no CSS errors in console
